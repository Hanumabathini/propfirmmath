# Economic calendar integration — PropFirmMath

## Live website
The `#/calendar` route in `site/index.html` embeds TradingView's economic-events widget in a responsive glass card. This is a third-party calendar; it is not generated by the Claude skill, and the site must not claim FMP data is live unless the FMP feed has actually been connected.

## Install the requested research skill in a Claude Code workspace
Run from the repository working directory:

```bash
npx skills add https://github.com/tradermonty/claude-trading-skills --skill economic-calendar-fetcher
```

Source: https://github.com/tradermonty/claude-trading-skills/tree/main/skills/economic-calendar-fetcher

The skill is an assistant-side Python/FMP research workflow, not browser JavaScript. It does **not** automatically make the GitHub Pages website show economic releases.

## Future first-party feed (not enabled)
- Configure `FMP_API_KEY` as a GitHub Actions repository secret, never in `site/index.html` or the public repo.
- Use the stable FMP endpoint `https://financialmodelingprep.com/stable/economic-calendar` (not retired v3).
- Run the fetch script in a scheduled GitHub Actions workflow; validate schema, dates, impact and response status; write a public sanitized `site/data/economic-calendar.json` only on successful retrieval.
- If FMP returns HTTP 402, the plan does not permit this endpoint; do not publish an empty calendar or silently claim zero events.
- Display source, fetch timestamp, UTC/local timezone and a stale-data warning; retain last verified data only with an explicit stale label.
- Do not expose API credentials, and do not infer firm-specific news trading permissions from macro events.

## Validation checklist
- Desktop and mobile width: no horizontal overflow; widget fits card.
- Browser: navigation `#/calendar` opens the page and the external TradingView script loads.
- If blocked by privacy extensions, show a visible link to the full provider calendar.
- Verify UTC/local times and DST against official agency announcements.
- Confirm economic events are not represented as firm rules.
